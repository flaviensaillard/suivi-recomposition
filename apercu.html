📱 Comment installer l'APK sur Android

  1. Téléchargez le fichier Equilibre.apk via le lien direct ci-dessus.
  2. Ouvrez le fichier téléchargé depuis vos notifications ou le gestionnaire de fichiers.
  3. Si Android vous demande l'autorisation d'installer des applications depuis cette source, validez « Autoriser cette source ».
  4. Appuyez sur Installer puis ouvrez Équilibre.
  5. L'application s'ouvre directement avec vos données locales hors-ligne et synchronisables avec votre base de données Supabase.

🌐 Coque d'applications Web Streamlit

L'onglet Apps Web de l'application permet de retrouver en un geste vos deux déploiements Streamlit (suivi-recomposition-corporelle.streamlit.app et menus-foyer.streamlit.app) sans jamais quitter l'application, avec le bouton de bascule instantanée.
